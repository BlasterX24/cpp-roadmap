Topic 20: File I/O

fstream, ifstream/ofstream, getline, binary I/O

File I/O uses fstream. ifstream reads; ofstream writes. getline reads lines. Binary uses read()/write(). Check is_open().

Quick Questions & Answers

Q1: ifstream vs ofstream?
A: Read vs write.
Q2: getline()?
A: Reads line with spaces.
Q3: is_open()?
A: Check if opened.
Q4: ios::binary?

Q5: read/write()?
A: Binary I/O.
Q6: ios::app?
A: Append mode.

A: When done.

A: Read position.
